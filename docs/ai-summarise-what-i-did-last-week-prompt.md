## What this does

Gives you a summary of last weeks work

To use the prompt 

run it as is, on any Ai tool that can access your work communications and documents. This has been used in Copilot.


```
summarise what i did last week.
output the summary to a word document.
save the word document with the filename in the format of yyyy-mm-dd.docx.

```

or

```
summarise what i did in the week 5th to 9th October.
output the summary to a word document.
save the word document with the filename in the format of yyyy-mm-dd.docx.

```

### Script history

This script originated from discussions about how to most effectively summarise mid-year, or end of year how a person is doing - by buiding up a library of information whilst still fresh in the memory, so that end of year performace and DDaT skills examples are much easier to write.

Perhaps even Ai could complete the DDaT skills evidecne automatically, for human final checking.

The idea for this prompt came from a couple of ideas.

The main one being, at a mid year or the end of the year, it's a lot of work to write up and present information at a performance review, and for DDaT Pay framework evidence.  

We thought if only run at the end of the year the summary would be too general.  In summarising, many things might get missed.  Also MS teams only keep m essages for 6 months, and other documents and emails might get deleted or moved from Ai access during the year - Shared information and documents should be considered temporary unless you have a copy.

We wondered if - as individuals we created our own source of information to be summarise at the end of the year - that could be a more effective way of reviewing.  So we might have as a maximum 52 weekly documents which are the source information about me, to query.  In reality we've not been running this prompt weekly.

In addition by doing this frequenlty, such as weekly, as Ai cant pick up all the work, for example work it does not have access to and unrecorded conversations (human to humn, or on teams calls) - where a lot of work happens.  Seeing a summary at the end of a week (or on a Monday about last week) is about the right frequency for the mind to recall other things I did and I can add those to the source document.  Thus creating a much stronger library of material.

A weekly reflection on my own work is also very useful.

I think the created library could be used for other purposes too.

I think Copliot is also using these summary queries to learn about me and makes stronger suggestions when prompting about other topics.  So it does seem there could be other benefits we'd not initialy considered.
